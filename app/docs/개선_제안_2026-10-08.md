# 개선 제안 — 화면·문안·관리 (2차)

작성일 2026-10-08 · 근거: 배포본과 같은 코드를 시연 모드로 띄워 11개 화면을 캡처해 보고, 코드의 용어·저장 구조를 함께 점검함. 실측 수치가 아닌 화면 관찰과 코드 근거만 적었고, 효과는 일반적 추론임.

## 요약
- 바로 고친 것(이번 커밋): 확정 팝오버를 가리던 말풍선 제거·주 버튼 색, '＋ 새 요구 시작'의 겹친 더하기 기호, 현황의 끝난 건 D-day(-92 같은 숫자)와 'None' 칸, 지표 데이터 미리보기의 번호 열.
- 1차로 권하는 것(작고 체감 큼): 홈 '오늘 할 일' 띠, AI 미연결 배너 축소, 다음 행동 칩, 용어 통일, 배포 버전 표시, 조직 설정 영속화, 자주 쓰는 문구 서랍, 백업·복원 버튼.
- 2차(구조 변경): 메뉴 재편(입구 하나), 검수 패널 세로 흐름·한 표 대조, 요청 주체 사전, 요구 건 상태 흐름(접수→처리→확정→발송→종결), 지표 데이터 보유 히트맵, 지표 사전 화면 편집.
- 3차(큰 기능): 답변자료 화면 미리보기, 회신 톤 프리셋, 월간 리포트, app.py 모듈 분리.

## A. 화면·디자인
| # | 제안 | 관찰·근거 | 난이도 |
|---|---|---|---|
| A1 | 메뉴 10개를 흐름 기준으로 재편: 업무(홈·현황·검토·승인) / 자료(지표 데이터·참고 문서·과거 답변 등록) / 기록(이력 조회와 이력에 묻기를 한 화면의 두 탭으로) / 설정. '새 요구서 처리' 3단계는 검수 패널의 '자세히 고치기'로만 진입 | 같은 일을 하는 입구가 둘(홈 대화, 3단계 화면)이고, 기록을 보는 화면도 둘(이력 조회·이력에 묻기) | 중 |
| A2 | 홈 상단 '오늘 할 일' 띠: 기한 3일 이내 N · 확정(미발송) N · 검토 대기 N · 이번 달 지표 데이터 미적재. 각 칸을 누르면 해당 화면 | 빈 홈은 설명문 3줄과 입력칸뿐이라 상태가 보이지 않음 | 소 |
| A3 | AI 미연결 배너를 첫 화면 한 번만 크게, 이후는 사이드바 상태 표시(이미 '규칙만 동작' 표시 있음)로 | 모든 화면 상단에 같은 노란 배너와 파란 버튼이 반복돼 본문 머리가 밀림 | 소 |
| A4 | 검수 패널을 탭 대신 세로 흐름으로: 머리에 진행 체크(읽기·등록·계획·값·대조·사유·초안·HWPX), 수치 표에 '지난번' 열을 붙여 한 표에서 대조(차이 행 색), 사유는 표 안에서 바로 입력 | 지금은 탭 4개를 오가며 같은 센터를 두 표에서 찾아야 함. 사유 입력칸이 행마다 한 줄씩 길게 늘어섬 | 중 |
| A5 | 답변자료 미리보기: HWPX를 받기 전에 제목·항목·표·근거를 화면에 문서 모양으로 보여 줌(생성기가 구조를 알고 있어 HTML로 그릴 수 있음) | 한글을 열어야만 결과를 확인함. 수정→다시 만들기→받기→열기 반복 | 중 |
| A6 | 빈 상태마다 바로가기: 참고 문서 없음 → 올리기 칸 강조, 지표 데이터 없음 → 대시보드 가져오기 버튼, 요구서 없음 → 홈으로 | 빈 상태가 설명문만 있음 | 소 |
| A7 | 좁은 창 대응: 검수 패널의 버튼 4열을 좁으면 세로로, 넓은 표는 '가로로 넘겨 보세요' 안내 | 1,180px 기준 고정 열 | 소 |
| A8 | 첫 접속 때 이름 선택 화면(목록에서 고르거나 추가) → 사이드바 '내 이름(기록용)' 펼침 제거 | 이름이 기본값 '담당자'인 채로 승인·발송이 기록될 수 있음 | 중 |
| A9 | 상태를 색만으로 구분하지 않기: 글자 배지 병기, 버튼 포커스 표시, 대비 점검 | 현황 표의 노랑·빨강·파랑 행 | 소 |
