## 3. 설계 원칙 — AI의 역할 경계
AI를 '변환'(글→구조, 구조→글)에만 쓰지 않고, 언어모델이 잘하는 **기억·예측·연결**에 씁니다.

| AI 핵심 역할 | 어디서 | 근거 제한 |
|---|---|---|
| 기억: 과거에 같은 차이를 어떻게 설명했는지 끌어와 문구 후보 제시 | 2단계 | 대조 단서 + 저장된 차이 사유 기록만. 원인 추측 금지 |
| 예측: 이 회신을 받은 요구 주체의 후속 질문과 준비할 자료 | 3단계 | 요구 항목·확정 수치 요약·대조 결과·타 기관 제출 이력·초안. 수치 해석 금지 |
| 연결: 자연어 질문을 조회 도구 호출로 바꿔 이력에서 답을 찾고 근거 레코드를 제시 | 이력에 묻기 | 읽기 전용 도구 결과만. 평균·증감 가공 금지 |
| 변환(보조): 요구서 구조화, 공문체 초안, 초안 점검 | 등록·1단계·3단계 | 사전 지표만, 확정 수치만 |

| AI가 하는 것 | AI가 하지 않는 것 |
|---|---|
| 요구서에서 항목·지표·기준일 추출(사전에 있는 지표명만) | 수치 계산·요약·추정(평균·증감도 계산하지 않음) |
| 확정 수치·입력된 사유만으로 문안 작성 | 차이 사유 추정 |
| 초안의 누락·불일치·단정 표현 지적 | 초안 자동 수정, 최종 판단 |
| — | 원자료(개인 단위 출결 등) 접근 |

구현 장치: 지표명은 JSON 스키마의 열거형으로 사전 값만 허용(지어낸 지표는 형식 단계에서 차단) → 사전에 없는 이름은 코드가 다시 걸러 null 처리. 데이터 없는 항목은 '[확인 필요]'로 남김. 대조는 pandas만 사용. 승인 없이는 확정되지 않음.

## 4. 아키텍처
- 화면: 홈(할 일·현황) → '새 요구서 처리' 3단계(읽기 → 수치 맞춰 보기 → 회신 초안, 단계 표시와 다음 버튼) → 검토·승인. 보조 화면: 과거 답변 등록·이력 조회·현황·이력에 묻기·설정. 색·글자 크기는 대한민국 디자인 시스템(KRDS) 토큰(주색 #256EF4, 본문 #1E2124, 연한 면 #EEF2F7)을 따르고, 화면당 파란 버튼 하나라는 절제 원칙(토스 디자인 원칙 참고)을 지킴. 글꼴 Pretendard(사내망에서 막히면 맑은 고딕). 샘플 선택칸은 시연 모드(APP_DEMO=1)에서만.
- 실행: 혼자 쓰면 `run.bat`(localhost), 여러 사람이 쓰면 부서 공용 PC에서 `run_server.bat` → 같은 망에서 접속. 접속자마다 자기 키를 설정 화면에 넣으며 키는 브라우저 세션에만 보관(서버 저장·공유 없음). 호출 기록·비용도 세션별.
- AI 공급자 모듈형: `providers.py` 인터페이스(기본 Anthropic Claude, '사용 안 함'). `provider_<이름>.py` 파일 하나로 사내 게이트웨이 등 다른 백엔드 추가(자동 발견, 기존 코드 수정 없음).
- 저장: SQLite 1개 파일(`storage/history.db`) — requests, items, submissions, submission_values(출처 포함), diff_reasons, drafts, reviews.
- 모듈: `extract`(추출) · `normalize`(지표 사전) · `search`(문자 n-gram 유사도, 외부 API 없음) · `suggest`(데이터 카탈로그) · `compare`(대조·점검표) · `pii`(개인정보 패턴) · `draft`(초안·충족 검사) · `hwpx_out`(HWPX 치환·행 복제) · `docread`(본문 추출) · `llm`(Claude 공통 호출) · `db`.
- LLM 호출(`llm.py`): 세션별 설정 주입(스레드 로컬), 모델 자동 대체(없음 시 후보 순), 구조화 출력(JSON 스키마) + 미지원이면 텍스트 파싱으로 자동 대체, 공급자 SDK의 429·5xx 자동 재시도, 호출별 모델·지연·토큰·추정 비용 기록. 키는 세션 입력 또는 서버 환경변수(파일 저장 안 함).
- 외부로 나가는 데이터: 요구서 문안(전화·이메일·주민번호·계좌 패턴은 **마스킹 후 전송**), 확정된 집계값(센터 단위), 담당자 입력 사유, 산출 근거 메타, (이력에 묻기) 질문 문장과 조회된 이력 레코드(요구서 제목·항목·센터 단위 값·사유. **직원 이름 필드는 제거**). 개인 단위 원자료는 전달하지 않음. 이력에 묻기의 조회 도구는 읽기 전용.
- 문서 형식: 입력 txt·HWPX·PDF·DOCX, 출력 HWPX(개방형 문서 전환 정책 방향과 부합 — `조사_배경자료` 4절).
