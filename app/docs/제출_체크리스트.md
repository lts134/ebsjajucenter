요강(대회 안내문 V-2) 기준. 마감 **2026. 10. 16.(금) 18:00**, AX추진팀 공용 메일(axteam@ebs.co.kr), 보고서·영상·산출물을 **ZIP 1개**로.

## 메일
- 제목: `[과제제출_트랙1] EBS 대외 요구자료 대응 에이전트_이택수`
- 본문에 넣을 것: 과제명, 대표자(부서·성명), 웹 접속 URL과 **접속 비밀번호**, 소스 저장소 주소, "AI 경로 확인 시 설정 → AI 연결에 Claude API 키 입력" 안내
- 첨부: `과제제출_트랙1_EBS대외요구자료대응에이전트_이택수.zip` (대용량이면 공유 드라이브 링크로 대체 가능)

## 보내기 전 확인(사람이 해야 하는 것)
1. **보고서 빈칸**: 참여자 정보의 '직급' [확인 필요] → 기입. 마지막 쪽 날짜·서명. `.docx`를 고친 뒤 PDF로 다시 저장(한글 또는 Word에서 '다른 이름으로 저장 → PDF'). 또는 `docs/build_report.js`의 `[확인 필요]`를 고치고 다시 생성.
2. **보고서의 [확인 필요] 항목**: 4-1 현재 소요 시간(담당자 실측), 외부 인용 수치 원문 확인, Litestream·Pretendard·Material Symbols 라이선스 표기, Google Cloud 저장 허용 여부. 확인 못 한 것은 표기한 채로 내도 되지만 비워 두지는 말 것.
3. **접속 비밀번호 변경**: 현재 값은 짧다. `.\update_cloud.ps1 -Project ebs-test-a2c4e -AppPassword 새비밀번호(10자 이상)` 후 메일 본문에 새 값 기재. 보고서·ZIP 안에는 비밀번호를 적지 않는다.
4. **서버 최신화**: `git pull` → `.\update_cloud.ps1 -Project ebs-test-a2c4e` (여러 출처 묶기·사이드바 수정 반영). 배포 후 URL 접속 → 설정 → 시연·초기화 → '시연 데이터 넣기'까지 한 번 눌러 심사위원이 바로 볼 수 있게 둔다.
5. **GitHub 공개 여부**: 저장소가 비공개면 심사위원이 못 본다. 소스 ZIP을 함께 내므로 필수는 아니나, 보고서 붙임에 저장소 주소가 있으니 공개로 바꾸거나 주소를 지울 것 [확인 필요].
6. **영상 재녹화(선택, 권장)**: 키가 설정된 PC에서 `set ANTHROPIC_API_KEY=...` 후 `python docs/record_demo.py` → Claude 경로(사유 후보·초안·후속 질문·이력 질의가 AI 결과)로 같은 흐름이 녹화되고 첫 자막이 "Claude API 연결 상태로 녹화"로 바뀐다. 3분을 넘기면 스크립트의 대기 시간을 줄인다. 재녹화 후 `python make_delivery.py`를 다시 실행.
7. **파일 열어 보기**: PDF 20쪽이 모두 보이는지, MP4가 재생되는지, ZIP 안 `app/run.bat`이 있는지.
8. **서약 사항 대조(서식3)**: 결과물은 직접 제작(코드 작성 보조로 Claude Code 사용, 보고서 '활용 AI 도구'에 기재), 오픈소스 출처·라이선스는 보고서 4-5에 명시, 사내 자료를 외부 AI에 입력하지 않음(가상 데이터 사용, 실 HWP는 PC 안에서만 처리).

