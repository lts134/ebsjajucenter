# 시연 시나리오 — EBS 대외 요구자료 대응 에이전트 (프로토타입)

- 소요: 약 15분(Claude 경로 기준). 규칙 경로로만 시연하면 약 11분
- 준비: `run.bat` 실행 → **설정**에서 API 키 입력 → **연결 테스트** 성공 확인(모델명·왕복시간 메모) → **이력 DB 초기화** 후 시작
- 데이터는 전부 가상(센터A~L, 수치 임의). 화면 캡처는 `docs/screens/` (규칙 경로, 2026-10-04 촬영). 발표자료는 `docs/발표자료_EBS_요구자료대응에이전트.pptx`
- 시작 전 사이드바에 담당자·검토자 이름을 넣어 두면 제출본·승인 기록에 그 이름이 남는다
- 시연 중 API 오류가 나면 각 화면이 자동으로 규칙 기반으로 대체되고 경고가 뜬다. 멈추지 말고 "키 없이도 같은 흐름이 돈다"로 넘긴다
- 실측 지연(10/04, claude-sonnet-4-6): 추출 3~10초, 사유 후보 15초, 초안 12초, 후속 질문 23~28초, 이력 질의 6~25초. 후속 질문·이력 질의는 버튼을 누른 뒤 기다리는 동안 설명을 이어갈 것. 캡처 9장은 Claude 경로

## 한 줄 메시지
"EBS가 언제, 누구에게, 어떤 근거로 답했는지 기억하고, 다음 답변의 수치와 문서를 검증한다." — AI는 추출·문안·점검만 하고, 수치 계산과 차이 사유는 코드와 담당자가 맡는다.

## 예상 질문과 답

| 질문 | 답 |
|---|---|
| AI는 어디에 쓰이나? 끼워 넣은 것 아닌가? | 변환(추출·문안)은 보조이고, 핵심은 세 가지: ③ 과거 사유·단서 근거의 문구 후보, ④ 후속 질문 예측, ⑧ 이력 질의. 전부 '기억·예측·연결'이고 수치는 건드리지 않는다 |
| AI가 수치를 틀리게 쓰면? | 초안은 확정 수치 표에서만 인용하고, 충족 검사(코드)와 Claude 추가 점검이 표에 없는 숫자를 잡는다. 최종은 팀장 승인 |
| 실제 요구서는 서식이 제각각인데? | 규칙 경로는 정형 서식 전제. 실제 운영은 Claude 경로. 점검 스크립트(`check_llm.py`) 결과: 실전형 5건 포함 9건에서 필수 쌍 25/25 (2026-09-28, claude-sonnet-4-6) |

| 사내망에서 API가 막히면? | 규칙 경로로 전 기능 동작(추출 정확도는 서식 의존). 허용 여부는 [확인 필요] |
| HWP(구형식)? | 읽기는 자동 변환으로 지원(python-hwpx). 암호·배포용 문서는 불가. 회신 출력은 HWPX |
| 개인정보? | 제출값에 주민번호·전화·이메일·학생 식별어 패턴이 있으면 ③에서 경고. 최종 판단은 담당자 |

## 실데이터로 바꿀 때(시연 후)
1. 제출값은 집계 엑셀(긴 형식), 실적표 서식 그대로(열 매핑), 회신 문서의 표, 직접 입력 중 편한 것으로. 실데이터 서식 1~2종을 먼저 올려 열 매핑이 맞게 잡히는지 확인
2. `normalize.py` CANON에 부서 지표·동의어 추가, `suggest.py` CATALOG에 출처·담당 기입
3. 실제 회신 서식 HWPX에 자리표시자 삽입 → `templates/`
4. `python check_llm.py`로 실제 요구서 몇 건을 `testcases.py`에 넣어 재채점
