# EBS 대외 요구자료 대응 에이전트 — 프로토타입

"EBS가 언제, 누구에게, 어떤 근거로 답변했는지 기억하고, 다음 답변의 수치와 문서를 검증하는 AI 에이전트."

## 실행
- `run.bat` 더블클릭, 또는 `python start.py`, 또는 VS Code에서 `app.py` 실행 — 셋 다 같은 동작
- 없는 모듈만 자동 설치(이미 있으면 건너뜀) → 브라우저에 앱이 열림. 종료: 터미널에서 Ctrl+C
- Claude API 키: 실행 전 `set ANTHROPIC_API_KEY=...` 또는 앱의 **설정** 화면에 세션 한정 입력 → **연결 테스트**로 모델·왕복시간 확인
  - 키가 없으면 규칙 기반(정규식·동의어 사전)으로 동작. 심사용 시연은 Claude 경로 권장
  - 요구서 원문의 전화·이메일·주민번호·계좌 패턴은 Claude에 보내기 전 자동 마스킹. ⑧ 도구 결과에서는 직원 이름 필드 제거
  - 워크스페이스에 묶이지 않은 키는 `ANTHROPIC_WORKSPACE_ID`(wrkspc_…)도 필요(설정 화면에 칸 있음). 워크스페이스 안에서 만든 키는 불필요
  - 호출에는 API 크레딧이 있어야 함(콘솔 Plans & Billing). 잔액 0이면 "credit balance is too low"로 거절됨
  - 모델은 `CLAUDE_MODEL`로 지정. 비우면 `llm.py`의 후보 순서(sonnet-4-6 → sonnet-5 → sonnet-4-5 → haiku-4-5)로 자동 시도

## 시연 순서 (샘플 데이터, 가상)
1. **① 과거 자료 등록**: `요구서_01_의원실_2026-07-01.txt` + `등원율_2026-06-30기준_7월제출본.xlsx` → 추출 → 저장
2. **② 새 요구서 분석**: `새요구서_의원실_2026-09-15.txt` → 분석 → "6/30 기준 등원율" 항목에 7월 제출 이력·산출 근거가 붙는지 확인 → 이력에 등록
3. **③ 수치 대조·점검표**: 새 집계값 = 9월 재산출 샘플, 과거 제출값 = #1 → 센터C·G·K 차이 + 단서(추출시점·원자료 버전 변경) → 사유 입력 → 점검표·개인정보 검사 → 확정
4. **④ 회신 초안·HWPX**: 초안 생성 → 충족 검사(+Claude 추가 점검) → HWPX 다운로드 → 제출 묶음 ZIP → 팀장 검토 요청
5. **⑤ 검토·승인** → **⑥ 이력 조회** → **⑦ 현황·통계**(D-day·관리대장·반복 지표) → **⑧ 이력에 묻기**("감사실에 등원율 어떻게 냈지?")
- AI가 핵심인 세 지점: ③ 사유 문구 후보(단서·과거 사유 근거) · ④ 예상 후속 질문 · ⑧ 이력 질의(도구 호출). 상세는 `docs/제출_설명서.md` 3절

## 점검
- `python run_checks.py`(또는 `run_checks.bat`): ruff → pytest 55건(`tests/`) → 추출 품질 점검 → 6단계 화면 흐름(AppTest)을 한 번에. 배포 전 모두 '통과' 확인
- `python check_llm.py` → 샘플 4건 + 실전형 5건(`testcases.py`, 전부 가상)을 규칙/Claude 양쪽으로 추출해 정답표와 비교
- 결과: `storage/llm_check_<날짜>.md`(채점표 + 사례별 추출 결과 + 호출 기록) / `.json`
- 규칙 경로는 이 사례들에 맞춰 조정된 것이므로 100%가 당연함. Claude 경로 점수와 오류 유형이 실제 점검 대상

## 실데이터 교체 방법
1. 제출값 엑셀 컬럼: `지표명, 센터명, 기준일, 값, 지표 정의, 집계기간, 추출시점, 원자료 버전` (한글 컬럼명·cp949 CSV·'2026. 6. 30.'·'67.8%' 허용, 시트 선택 가능. `compare.load_values`의 rename 표 참고)
2. 부서 지표명을 `normalize.py`의 CANON에 추가(동의어 포함) → 추출·검색·제안·충족 검사가 같은 이름을 씀
3. 데이터 출처·담당을 `suggest.py`의 CATALOG에 기입
4. 실제 회신 서식 HWPX를 한글에서 열어 `{{수신}} {{제목}} {{본문}} {{차이사유}} {{산출근거}} {{row.center}} {{row.value}}` 등 자리표시자를 넣고 `templates/`에 저장

## 알려진 한계
- 유사 검색은 임베딩이 아닌 문자 n-gram 유사도(사내 PC 완결)
- HWP(구형식) 미지원 — HWPX로 저장 필요. 자리표시자는 한 문단 안에 있으면 run이 쪼개져 저장돼도 인식됨(2026-10-04)
- 충족 검사 규칙 판정은 '지표명 언급 여부' 수준
- 규칙 기반 추출은 정해진 서식(줄머리 번호·'기준' 표기)에 의존 — 실제 요구서는 Claude 경로 필요
