# 2026 활용수기 공모 온라인 접수

자기주도학습센터.kr에 올리는 공모 접수 페이지와 관리자 페이지입니다. Firebase(서울 리전)에 접수 정보와 PDF를 저장합니다.

## 파일 구성

| 파일 | 용도 | 올리는 곳 |
|---|---|---|
| `apply.html` | 학생 접수 페이지 | 홈페이지 (팝업에서 이 주소로 연결) |
| `admin.html` | 관리자 페이지 | 홈페이지 (주소는 비공개로 관리) |
| `firestore.rules` | 접수 정보 보안 규칙 | Firebase 콘솔 > Firestore > 규칙 |
| `storage.rules` | PDF 파일 보안 규칙 | Firebase 콘솔 > Storage > 규칙 |
| `cors.json` | 관리자 페이지에서 PDF를 받기 위한 설정 | Google Cloud Shell에서 1회 적용 |

## 처음 설정 순서

1. **프로젝트 만들기**: 공식 Google 계정으로 [Firebase 콘솔](https://console.firebase.google.com)에서 새 프로젝트를 만듭니다.
2. **요금제**: 프로젝트를 Blaze(종량제)로 바꿉니다. Google Cloud 콘솔 > 결제 > 예산 및 알림에서 월 10,000원 예산 알림을 설정합니다. 알림은 메일만 보내고 사용을 멈추지는 않습니다.
3. **Firestore 만들기**: Firestore Database > 데이터베이스 만들기. 위치는 `asia-northeast3 (서울)`, 이름은 기본값 `(default)`로 둡니다.
4. **Storage 만들기**: Storage > 시작하기. 위치는 `asia-northeast3 (서울)`을 선택합니다.
5. **웹 앱 등록**: 프로젝트 설정 > 내 앱 > 웹 앱 추가. 표시되는 `firebaseConfig` 값을 `apply.html`과 `admin.html` 상단의 `FIREBASE_CONFIG`에 똑같이 붙여넣습니다.
6. **로그인 설정**: Authentication > 시작하기 > 로그인 방법에서 Google을 사용 설정합니다. Authentication > 설정 > 승인된 도메인에 `xn--ok0bv9ht5mcnbrxlpkcd3xm0h.kr`(자기주도학습센터.kr)을 추가합니다.
7. **보안 규칙 게시**: `firestore.rules`, `storage.rules` 내용을 각각 규칙 탭에 전체 붙여넣고 게시합니다. Storage 규칙을 게시할 때 Firestore 접근 권한을 부여하라는 안내가 나오면 허용합니다.
8. **CORS 적용**: Firebase 콘솔 오른쪽 위 Google Cloud 콘솔로 이동 > Cloud Shell을 열고 `cors.json`을 업로드한 뒤 아래 명령을 실행합니다. 버킷 이름은 프로젝트 설정의 `storageBucket` 값입니다.
   ```
   gcloud storage buckets update gs://버킷이름 --cors-file=cors.json
   ```
   홈페이지 주소가 다르면(예: 다른 도메인에서 관리자 페이지를 연다면) `cors.json`의 `origin`에 그 주소를 추가합니다.
9. **관리자 등록**: 홈페이지에 올린 `admin.html`을 열어 공식 계정으로 로그인합니다. "관리자 권한이 없습니다" 화면에 나오는 UID를 복사합니다. Firestore > 데이터에서 컬렉션 `config`, 문서 ID `admins`를 만들고 필드 `uids`(배열)에 UID를 넣습니다. 관리자를 추가할 때도 이 배열에 UID를 더합니다.
10. **응모 기간 설정**: `admin.html`을 새로고침하고 [응모 기간 설정]에서 시작·마감 시각(한국시각)을 저장합니다. 기간이 없으면 접수 페이지는 제출을 받지 않습니다. 나중에 언제든 바꿀 수 있습니다.

## 운영 전 확인할 문구 [확인 필요]

`apply.html`에서 아래 항목을 확정한 값으로 바꿉니다.

- `GRADE_OPTIONS`: 응모 대상 학년
- `CENTER_OPTIONS`: 센터 목록 (비워 두면 학생이 직접 입력)
- `CONTACT_TEXT`: 문의처
- 개인정보 수집·이용 안내 표의 **보유 기간**
- 처리 위탁 문구의 수탁자 법인명 (Google LLC 여부)
- 자기주도학습센터.kr 개인정보 처리방침에 위탁 사항(수탁자: Google, 업무: 공모 접수 정보·파일 저장) 추가

## 공개 전 시험 (실제 프로젝트에서)

| 시험 | 기대 결과 |
|---|---|
| 로그인하지 않은 휴대폰으로 PDF 제출 | 접수번호 표시 |
| 한글(.hwp) 파일 또는 10MB 초과 파일 제출 | 제출 거부 안내 |
| 응모 기간 밖에서 제출 | 제출 거부 |
| 관리자로 등록되지 않은 다른 Google 계정으로 `admin.html` 로그인 | "관리자 권한이 없습니다" |
| 관리자 계정으로 PDF [보기] | PDF가 새 탭에 열림 (안 열리면 8번 CORS 확인) |

시험 제출 건은 관리자 페이지에서 상태를 "제외"로 바꾸거나, 공개 직전에 [전체 파기]로 지웁니다.

## 운영 중 유의사항

- **블라인드 심사**: [심사용 ZIP]은 파일명을 심사번호로 바꿉니다. 동의서 쪽 수를 입력하면 PDF 뒤쪽에서 그만큼 빼고 묶습니다. 학생이 순서를 바꿔 넣었을 수 있으니 몇 건은 직접 열어 확인합니다.
- **파일 전달**: 심사위원에게는 링크가 아니라 내려받은 파일로 전달합니다.
- **중복 제출**: 성명·학교·보호자 연락처가 같으면 마지막 제출본에 "최종본", 이전 것에 "이전본"이 표시됩니다. 이전본은 "제외"로 처리합니다.
- **파기**: 보유기간이 끝나면 관리자 페이지 [전체 파기]로 삭제하고, 파기 일시와 건수를 기록합니다.
- **외부 파일**: 두 페이지는 `www.gstatic.com`(Firebase), `cdnjs.cloudflare.com`(엑셀·ZIP·PDF 처리), Google Fonts를 불러옵니다. 홈페이지 보안 설정에서 이 주소들이 막혀 있으면 동작하지 않습니다.

## 보안 규칙 요약

- 학생(로그인 없음): 응모 기간 안에 **새 접수만** 가능합니다. 조회·수정·삭제는 할 수 없습니다. PDF·10MB 이하·무작위 파일명만 허용하고, 이미 있는 파일은 덮어쓸 수 없습니다.
- 관리자(`config/admins`에 등록된 UID): 조회, 다운로드, 처리 상태·메모·심사번호 수정, 삭제가 가능합니다. 학생이 낸 신청 내용은 관리자도 고칠 수 없습니다.
- 응모 기간은 서버 시각으로 판단하므로 학생 기기 시계를 바꿔도 마감 후에는 제출할 수 없습니다.
